Pick another colour

Peach did not work, so here are six new directions on the same white page. Each one replaces Vinted's teal everywhere it appeared: main buttons, outline buttons, links, the buyer price line, the active tab, selected filters, banners and badges. Green stays for sold, amber for warnings, red for errors. Where the accent is close to one of those, that option adjusts the state colour so they stay easy to tell apart.

Light mode only, real clothing photos. This page sits next to the first one (colour-options.html), which is kept for reference.

How to choose
  1. Start with the home feed. Which colour lets the clothing photos look best?
  2. Check the buttons in the item page bar. Which one feels like the main action without shouting?
  3. Every option passes the accessibility contrast check, so choose by feel. The table under each one is the proof.
