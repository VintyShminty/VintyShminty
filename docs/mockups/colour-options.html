Pick the colour

VintyShminty needs a colour. This page shows three white-and-peach directions on the same screens, so you can compare them side by side. Peach takes the place of Vinted's teal everywhere it appeared: main buttons, outline buttons, links, the buyer price line, the active tab, selected filters, banners and badges. Green stays for sold, red for errors and amber for warnings.

Light mode only. The clothing photos are real, because the palette has to frame photos, not fight them.

How to choose
  1. Look at the home feed first. Which one makes the photos look best?
  2. Look at the buttons in the item page bottom bar. Which one feels like the main action without shouting?
  3. Read the price lines at arm's length. Every option passes the accessibility contrast check, so choose by feel.
  4. Check the table under each option if you want proof. Every pair is measured.
Option A

Soft peach

Primary buttons in a soft peach fill with deep brown text. Prices and links in a deeper terracotta that reads on white.
