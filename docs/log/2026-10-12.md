### Problems and fixes

- **Hebrew text hugged the left edge.** Root cause: in right to left mode the phone swaps left and right, so the text component's "align right for Hebrew" was flipped back to the left. Fix: always align to the start edge, which is right in Hebrew (`4abebb7`). Lesson: in right to left layouts use start and end, never left and right.
- **The pull request check failed.** Root cause: the new vulnerability scan found two serious issues in Expo's build tools with no fixed version available. Fix: accept those two by name with a reason and a recheck date, keep the scan strict for anything new (`4c4e85f`).
- **Face ID and right to left do not work in Expo Go** (the quick preview app). They need a development build of the app (`npx expo run:ios`), which is now set up on the Mac (CocoaPods installed).
- **A restart interrupted the Accounts helper.** It resumed from its saved state with no work lost, because everything finished was already pushed.
