### Problems and fixes

- **Everything blocked at once.** Root cause: main stood still for a month while new warnings were published about add-ons we already had. Lesson: merge small things often and deal with Dependabot weekly, so fixes stay small.
- **A new warning landed halfway** (picomatch), right after #155 went in, and blocked every PR again. Fixed with a small PR of its own (#157) so the other PRs did not have to wait on anything bigger.
- **The version rule could not reach vite.** The test runner does not install vite itself, it expects us to bring it, and overrides do not apply to that kind of add-on. Fix: list vite directly next to vitest in each package.
- **Installs hung for minutes.** After a version change pnpm tried to download Next.js and Biome pieces built for Windows and Linux and kept retrying. Fix: write the version list first (`pnpm install --lockfile-only`), then install only what this Mac needs, with a time limit.
- **The code style check failed only on GitHub for #156.** Biome 2.6 wanted to reformat Markdown tables. Fixed by keeping Biome at 2.5.15.
