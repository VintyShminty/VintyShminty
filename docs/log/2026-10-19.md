## Product name search and trademark checks

### What was done
- Brainstormed names to replace Yadii, with no "yad" in them, so there's no reason for a dispute with Yad2.
- Checked shortlisted names in the WIPO Global Brand Database (a worldwide trademark search that includes Israel) and in the official Israeli registry, the Israel Patents Office search site (trademarks.justice.gov.il). Also searched the web for apps already using each name.
- Learned what Eden likes: short, catchy, sharp names like Gett, Wix, Waze and Etsy. A name does not have to mean anything. Forced doubled letters and meaning-heavy Hebrew words did not land.

### Decisions
- No final name yet, so nothing is recorded in `docs/design.md`.
- Dropped after the checks:
  - Dibs: 1stDibs is a big vintage marketplace whose stock symbol is DIBS
  - Kwik: an Israeli company called Kwik Commerce held it for software until 2025
  - Flipp: an Israeli company holds FLIP for software, and Flyp is a US clothing resale app
  - Bartr: taken for trading apps in the US, UK, EU and Australia
  - Nisha (נישה): registered in Israel for online retail
  - Local: an everyday word, too generic to own
  - Radius (רדיוס): owned by the 100FM radio company
  - Hoppa: set aside
- Still in the running:
  - **Boidem** (בוידעם, בוידם): free in the Israeli registry in every spelling, and no Boidem trademark anywhere in the world. The only near match is an old, closed "Vintage Boydem Collection 1978" application for sunglasses, plus a Canadian clothing brand called "Boydem" registered in Canada only. This answers the "is the name free" question above for trademarks. Company name, domain, App Store and social handles are still not checked.
  - **Kazu**: no trademark in Israel, and nothing similar in shopping abroad.
  - **Dropp**: no Dropp in Israel, and the "Drop" trademarks there are for other products. Abroad there's a US payments app and an Icelandic delivery company with the name.
  - Ruma: free in Israel, but a South African fashion shopping app already uses it.

### Problems and fixes
- The Israeli registry was down at first, showing a "temporary problem" message. The WIPO database was used instead.
- WIPO forgets its filters when you open a results address directly. The fix was to search through the site's own search box and filter panel.
- Later the Israeli registry worked, but every search came back empty, even "DROP". The cause was a "no results" pop-up that caught the next words typed. The fix was to close the pop-up first, then prove the search worked on known words ("DROP" found 35 records, ארון found 10) before trusting an empty result.
- Lesson: before believing "nothing found", run a test search for something known to exist.

### Open questions
- Which name? Suggested default: Boidem if Israel comes first, Kazu if the brand should work abroad too.
- Before committing to a name, a short consult with an Israeli trademark lawyer to confirm and file it.

### Next steps
- Eden picks a name. Then record it in `docs/design.md`, update `docs/originality.md`, and change the wordmark, logo letter (D-046) and app wording.

## Android app for a partner, without the Play Store

Branch: `feat/android-apk`

### What was done
- A partner with an Android phone can now install the app from a plain download link, no Play Store needed. The first build is ready (Expo build `098d5854`).
- The build talks to the live server, so the partner sees the same listings as Eden's iPhone and they can message each other.
- It is signed with the same key as the Play Store build (so Google sign in should work) and gets the same silent updates as the production builds.
- The new build type is called `apk` in the Expo build settings. To make another one: `npx eas-cli@latest build --platform android --profile apk`.

## Bot check and website security rules

Branch: `feat/turnstile-security`

### What was done
- Checked Eden's 12 item security and safety list against the code. Already in place: protection from database tricks (SQL injection), the delete account button (website and app), the 6 digit code at sign up, request limits per minute, and HTTPS on Vercel. Font and icon licences are fine for a business (Aileron CC0, Heebo OFL with its licence file, Lucide ISC). Missing: the accessibility statement page, a bot check, auto save, an offensive word filter.
- Built the bot check (Cloudflare Turnstile) on sign up, log in, emailed code requests and the Help question box, on the website and in the app. Usually invisible. If Cloudflare is unsure, a small tick box shows (website: bottom of the screen, app: a small card). The app runs it in a hidden web view of the website's new `/app-check` page, because Cloudflare's check only works in a web page.
- The server asks Cloudflare whether each answer is real. A wrong answer is refused. A missing answer is let through while `CAPTCHA_REQUIRED` is false, so today's app versions keep working.
- Website security rules: only our own scripts, stamped with a fresh random number on each visit, may run (Content Security Policy), always HTTPS (HSTS), no other site may frame our pages.
- Tested locally: a code request without an answer is refused, the real forgot password form goes through, the home page shows no blocked content. Typecheck, lint and tests green.

### Decisions
- Cloudflare Turnstile over Google reCAPTCHA (Eden): free, usually invisible, more private, Eden already has Cloudflare.
- The check covers both website and app (Eden), not only the website, because a bot could otherwise pretend to be the app.
- Affiliate link disclosure skipped: the site has no affiliate links. "Invite friends" is between users, not paid advertising.
- If Cloudflare is down, calls go through (logged) so nobody is locked out. Rate limits still apply.

### Problems and fixes
- None worth noting.

### Open questions

- Two-factor: suggested default is an email code on a new device.
- Offensive words: suggested default is to block and ask to rephrase, in listings, usernames and chat.
- Auto logout: suggested default is to keep 30 days.
