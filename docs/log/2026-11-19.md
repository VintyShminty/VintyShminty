# 2026-11-19

Branch: `docs/log-2026-11-19` (the work itself went out in #166 to #169, all merged)

## What was done

- **Red stars on the sell form, website and app.** Every field a seller must fill now has a small red star after its name: Photos, Name, Category and Price always, and Brand, Size, Condition, Colours, Material and Pattern only when the chosen category needs them. Screen readers say "required" instead of the star. Checked on the website and in the iPhone Simulator in English and Hebrew (the star sits at the end of the word, on the left in Hebrew). #167, D-061.
- **Zoom into listing photos.** In the app, tapping a photo on a listing now opens it full screen (before, nothing happened): pinch or double tap to zoom, drag to look around, swipe between photos, drag down to close. It reuses the sell form's photo viewer without the crop and rotate buttons. On the website, a click on the full-screen photo zooms in on that spot, the mouse looks around, a second click zooms out. #168, D-062.
- **Main folder caught up.** The main project folder was on an old branch, 171 changes behind, with a pile of unsaved edits. Almost all of those edits were already in main or replaced since (old Yadii wording). They are kept in a local backup branch `backup/old-folder-2026-11-19`, and the folder is now on main and clean.
- **Five leftover documents saved.** Two daily logs (2026-10-19 and 2026-11-07), the colour mockups 3 and 4 (D-060 points to number 4) and the 16 October security handoff note were only in that folder. They are in main now. #166.
- **Updates sent.** The website went live by itself after the merges. The iPhone app got a silent update with both changes (it matches build 8, the Basta build). A new Android APK was started on Expo's servers from main `92a5da9`.
- **Silent updates now go to Android too.** The update command used to send to iPhones only. #169.

## Problems and fixes

- **The Simulator build seemed to fail.** The app built and installed fine. Only the very last step, bringing the Simulator window to the front, failed, and that also stopped the bundler (the helper that feeds the app its screens). Fix: started the bundler on its own and opened the app with its link. Lesson: read the end of the build output before rebuilding.
- **Local test logins did not work.** The saved test passwords were out of date. Fix: `pnpm db:dev-users` gave the three sample people new ones (local database only).
- **Android could not take the silent update.** The installed APK and the Play build were made before the Basta rename, which changed built-in parts (name, icon, colours), so their fingerprint (the app's built-in version stamp) no longer matches. A silent update only reaches matching installs, so Android needs the new APK once. The iPhone build 8 does match: its stamp is inside the archive at `Basta.app/EXUpdates.bundle/fingerprint`.
- **Checked before publishing the security note.** The repository is public. Both issues in the 16 October note were already fixed in main (the login link check is strict and the old Face ID lock screen is gone), so it was safe to publish.
