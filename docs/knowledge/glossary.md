# Glossary

Plain-words meanings. Added by the `compile-memory` skill.

- **Monorepo.** One folder holding the app, the server and the database code together.
- **Milestone.** A stage of the roadmap that ends with something Eden can use on his phone. See `docs/roadmap.md`.
- **Branch.** A separate line of work that does not affect the main version until it is merged.
- **Pull request (PR).** A request to merge a branch into another, where checks run and Eden reviews.
- **Worktree.** A second folder on the Mac holding another branch, so two agents never step on each other.
- **CI.** The automatic checks GitHub runs on every upload: types, style, tests.
- **Migration.** A saved step that changes the database structure, so every machine ends up the same.
- **Seed.** Starting data loaded into a development database. Reference seed is real (categories, brands). Sample seed is fake.
- **Server.** The program online that holds the rules and talks to the database. The app asks it for everything.
- **Zod schema.** A written description of what valid data looks like, checked by both app and server.
- **State machine.** The fixed list of steps an order or offer can go through and the moves allowed between them.
- **RTL.** Right to left layout for Hebrew. The whole screen mirrors.
- **Token.** A named design value (a colour, a gap, a text size) so it is changed in one place.
- **Simulated checkout.** In version 1 Pay always succeeds and no money moves.
- **Minor units.** Money as whole agorot (cents), stored as an integer to avoid rounding errors.
- **Better Auth.** The sign in library used from Milestone 1.
- **Cloudflare R2.** Online storage for photos. The bucket is `vinty-photos`.
- **Expo.** The tool that builds the phone app and lets Eden preview it.
- **Development build.** A version of the app built for the Mac and simulator that can do Face ID and real right to left, unlike Expo Go.
- **Expo Go.** The quick preview app. Good for fast looks, but no Face ID and no forced right to left.
- **Supply chain.** The outside libraries the app is built from. We only install versions at least 7 days old and scan for known vulnerabilities.
- **Trailing and leading edge.** The end and start of a line. Right and left in English, left and right in Hebrew.
- **Push panel.** A full-screen page that slides in from the trailing edge and shoves the current screen aside. Used for categories and filters.
- **Product spec.** The Vinted UX deconstruction. Where we have not decided something ourselves, we follow it for how things work, never for names, wording or looks (`docs/originality.md`).
- **Vercel.** The company that runs the server online. Project `vinty-shminty`, address `https://vinty-shminty.vercel.app`.
- **Deploy.** Putting a version of the server online. A merge into `main` deploys by itself.
- **Environment variable (setting).** A named value the server reads when it starts, like the database address. Secret ones live only in Vercel.
- **Neon.** The online Postgres database (`vinty-db`, Frankfurt).
- **Redis (Upstash).** A fast shared memory that lets the server copies pass chat messages to each other.
- **Cron job.** A scheduled alarm. Vercel calls `/v1/jobs/all` once a day on the free plan.
- **App ID (bundle id).** The app's permanent identity with Apple and Google, `com.secondhand.marketplace`. Users never see it.
- **App Store Connect.** Apple's website for apps. Our entry is "Shminty".
- **TestFlight.** Apple's app for installing test versions before the App Store.
- **EAS.** Expo's build service. It builds the iPhone app on Expo's computers and uploads it to Apple.
- **OAuth client (login key).** The pair of values Google gives so our server may offer "Continue with Google".
- **Test user.** A Google account allowed to use Google login while it is in testing mode.
- **Account linking.** Connecting a Google or Apple login to an existing Vinty account with the same email.
- **Coverage.** Our name for buyer protection (placeholder in one key, `protectionName`). The buyer is protected and we step in if the item does not arrive or is not as described.
- **Boost / Boosted (הקפצה, מוקפצת).** A seller moves a listing to the top of the feed for a while ("Boost this listing", "להקפיץ את המודעה"). Free for now. The listing shows "Boosted" until it ends. Called Buzz until 2026-10-15, and still "buzz" and "bump" inside the code.
- **Yadii.** The name the app shows now (#83). Still a candidate, not final (`docs/originality.md` G10).
- **Wordmark.** The app name written in bold as a logo, at the top of Home (D-047).
- **Expense items.** Yearly and one time costs in the admin Expenses page, each with a "Paid by" name.
- **Place suggestions.** Google's city and address guesses while you type a profile city or delivery address, fetched through our server.
- **Away mode.** A Settings switch that hides your items, with an optional return date.
- **Invite code.** A personal code a friend types when joining. After their first order above the minimum both get a 50 shekel voucher.
- **Mood chips.** The row of filters on Home: Women and Men first, a divider, then New today, Price, Your sizes, Near you. The plain Home is For you. Until 2026-10-17 there were For you and Under 50 shekels chips (#118, D-056).
- **Price chip.** The Home chip that opens a small panel (a sheet on the phone) with quick price picks and From and To boxes, then shows the range chosen (D-056).
- **Looks like.** The first group in a picker, showing the AI's best guesses. It never fills anything in by itself.
- **Claude Haiku.** The small, cheap Anthropic AI model behind every AI feature.
- **Review list.** One page in the admin pages with user reports and the AI's listing flags, urgent first. Eden decides.
- **Card copy / blur.** A small lighter copy of each uploaded photo and a soft colour blur shown while it loads.
- **Bundle (באנדל).** Several items from one seller bought together, with the seller's discount steps and one postage fee. Was "Closet deal" (D-049).
- **Bundle pill.** The rounded espresso bar that floats above the tab bar once you add something to a bundle (D-050).
- **Bundle steps.** A seller's discount ladder, for example 2 items 5% off, 3 items 10%, 5 items 15%. Set in Settings, Bundles.
- **Over the air update (silent app update).** New screens, wording or fixes sent to installed apps without a TestFlight build (`pnpm update:live`). Native changes still need a build.
- **Runtime version (native fingerprint).** A code that says which native parts an app build has. An over the air update only reaches builds with the same code (build 7 is `7f56999f`).
- **Explore, Chats, Saved.** The English names of the Browse tab, the Inbox tab and the Favourites list since 2026-10-17, so they no longer match Vinted's (#124). Inside the code they are still browse, inbox and favourites.
- **Shopping groups.** Women, Men and Kids, the answer to "What do you shop for?". Home and search show your groups first (D-048).
- **Corner.** A small part of another shopping group you showed interest in, for example women's cycling clothes. Only that corner moves up, not the whole group.
